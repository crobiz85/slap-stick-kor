이전 `v0.1.10-alpha`와 `v0.1.12-alpha` IPS는 비교·복구용으로 보존합니다.

원본 ROM, 패치 적용 완료 ROM, BPS 및 배포 ZIP은 포함하지 않습니다.

공개 업데이트는 큰 문제를 해결하고 실제 진행을 확인한 경우를 원칙으로 하며,
이번처럼 사용자가 테스트 후 명시적으로 요청한 버전도 공개합니다.
작은 수정은 로컬 테스트본으로 누적하며, 미공개 테스트 IPS는 Git에서 제외된 `build/`에 둡니다.

게임 ROM의 저작권과 상표권은 각 권리자에게 있습니다. 이 패치는 비공식 팬 번역이며,
합법적으로 소유한 원본에 개인적으로 적용해 사용하세요. 적용 결과 ROM은 배포하지 마세요.
