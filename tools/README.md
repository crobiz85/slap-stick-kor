# 도구 메모

이 폴더에는 현재 도구에 대한 사용 메모와 재현 절차를 기록합니다. 원본 실행 파일은 상위 작업 폴더에 보관하되 Git에는 포함하지 않습니다.

현재 확인된 도구:

| 파일 | 용도 |
| --- | --- |
| `Hex_Search.exe` | ROM 바이트 검색 |
| `Table_Generator.exe` | 문자 테이블 생성 |
| `United_Script_Editor_v241015.1.exe` | 스크립트 추출·편집 |
| `6502_65816_Assembler_v1.1.zip` | 65816 어셈블러 |
| `le120.zip` | Lunar Expand 1.20 (SNES ROM 확장) |

압축 파일의 README를 확인한 결과:

- `6502_65816_Assembler_v1.1.zip`은 65816 어셈블/역어셈블과 기준 주소 입력을 지원합니다.
- `le120.zip`은 12 Mbit 원본을 바로 수정하는 도구가 아니라, 필요할 때 ExHiROM으로 확장하는 도구입니다.
- Lunar Expand 문서에는 RoboTrek이 호환성 ExHiROM 옵션을 사용해야 했던 사례가 적혀 있으므로, ROM 확장은 텍스트 공간이 부족하다는 근거가 확인된 뒤에만 검토합니다.

실행 파일은 GUI 도구로 보이며, 첫 단계에서는 ROM을 복사본으로 작업하고 원본은 변경하지 않습니다.
